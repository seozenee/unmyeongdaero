# Pretendard

보고서 PDF 에 심는 한글 글꼴. 화면은 시스템 글꼴을 쓰지만, PDF 는 받는 사람의 컴퓨터에
무엇이 깔려 있든 같은 모양으로 보여야 하므로 파일째 넣는다.

- 출처: https://github.com/orioncactus/pretendard (v1.3.9)
- 라이선스: SIL Open Font License 1.1 — `Pretendard-OFL.txt`
- 받은 파일: `public/static/alternative/` 의 TTF. react-pdf 는 OTF·가변 글꼴을 읽지 못한다.

굵기는 셋만 넣는다(Regular 400 / SemiBold 600 / Bold 700). 더 넣으면 배포 용량만 늘고
지면에서 구분되지 않는다.
