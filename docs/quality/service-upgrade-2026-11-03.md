# 사주 서비스 개선 및 출시 검증

## 적용한 개선

- 11폴더의 설명 흐름과 용용사주의 주제별 탐색·장별 읽기 방식을 참고했다. 첨부 이미지의 개인 정보와 문장은 복사하지 않았다.
- 전체 상품 상세의 문체 예시를 공통 컴포넌트로 정리했다. 가상 명식 예시임을 명시하고 펼쳐 읽을 수 있다. 종합·평생·팩폭 상세에도 연결했다.
- 대표 상세에 실제 목차 개수, 12개월 열람, PDF, 단건 결제 안내와 관련 상품 이동을 추가했다.
- 홈에서 고민별 바로가기를 상품 목록보다 먼저 배치했다.
- 종합 목차의 반복 설명을 줄이고, 각 장에서 읽을 내용을 구체화했다.
- 재회·건강·사업·입시 판매 문구를 실제로 제공 가능한 설명 범위에 맞췄다.
- 리포트에 큰 글씨, 진행률, 키보드 이동, 같은 브라우저에서 읽던 페이지 복원을 추가했다. 저장 공간에는 풀이 본문이나 생년월일을 넣지 않는다. 브라우저 저장소를 사용할 수 없어도 읽기는 계속된다.
- 설명의 근거·생활 장면·장점과 부담을 잇는 작성 지침을 보완했다.
- AI 결과에 설명 부족, 문단 반복, 장별 결론 중복, 임시 문구 검사를 추가했다. OpenAI 경로는 실패 시 기존 검수 재시도를 사용하며, 모든 AI 제공자는 저장 전 검사를 통과해야 한다. 개발용 템플릿에는 분량 검사를 강제하지 않는다.

## 검증

- `pnpm test`: 432개 통과, 외부 API 테스트 1개는 기본 실행에서 제외.
- `pnpm build`: 성공. 타입·린트·토큰·시드·PDF 배포 파일 추적 검사 포함.
- 빌드 중 외부 Google Fonts 최적화 다운로드 경고가 있었다. 빌드는 완료됐다.
- 데스크톱: 대표 상세 예시 펼치기, 시작 버튼 → 이야기 → 정보 입력 진입 확인.
- 모바일 390×844: 장 목차 이동, 큰 글씨, 페이지 버튼, 새로고침/재진입 후 5페이지 복원 확인. 브라우저 오류 로그 없음.
- 실제 OpenAI 생성: 가상 고객 팩폭 풀이 1건, 82.35초에 생성·검수 통과. 9개 장, 장마다 6~7문단·596~847자. 설명·반복·목차·근거 검사를 통과했다. 이 한 건의 통과는 모든 고객의 해석 정확성을 보장하지 않는다.

## 정식 판매 전에 남은 확인

`pnpm launch:check`는 `.env.local`을 읽으며 키의 실제 값은 출력하지 않는다. 로컬 설정을 검사한 결과는 다음과 같다. 배포 환경의 설정 상태를 의미하지 않는다.

- 토스 클라이언트·시크릿 키: 실결제 키 확인 필요.
- 서비스 주소: 공개 HTTPS 도메인 설정 필요.
- 실제 결제 승인·취소·권한 회수, 운영 로그인, 알림톡 수신은 이 변경 작업에서 실거래로 검증하지 않았다.
- 운영 배포 및 서비스 등록은 수행하지 않았다.

출시 설정 검사만 통과했다고 운영 준비 완료로 판단하지 않는다. 실제 운영 환경에서 로그인 → 명식 확인 → 결제 → 풀이 생성 → 보관함 → PDF와 취소 흐름을 확인해야 한다.
