# 결제경로 캡처

`node scripts/build-payment-path.mjs` 가 이 폴더의 파일을 읽어 PPT 를 만듭니다.
파일 이름이 정해져 있으니 그대로 두세요. 없는 캡처는 PPT 에 빈 자리로 표시됩니다.

| 파일 | 찍을 화면 |
|---|---|
| `02-하단정보.png` | 아무 페이지나 맨 아래 — 사업자정보가 보이게 |
| `03-환불규정.png` | `/refund` |
| `04-로그인.png` | `/login` — 이메일 로그인 칸을 펼친 상태 |
| `05-상품목록.png` | `/` 첫 화면의 상품 목록 |
| `06-상품상세.png` | `/reports/life` |
| `07-정보입력.png` | 생년월일시 입력 화면 |
| `08-만세력확인.png` | `/readings/{id}/manse` |
| `09-주문확인.png` | `/checkout/life?reading={id}` — 결제수단·동의까지 보이게 |
| `10-결제창.png` | 토스페이먼츠 카드 결제창 |
| `11-카드사인증.png` | 카드사 인증 화면 (비씨카드는 필수) |

## 찍을 때 지켜야 하는 것 (토스 가이드)

- **북마크바를 끄고** 주소창의 도메인이 보이게 찍습니다.
- **PC 시계가 함께 나오게** 찍습니다 — 심사가 시간 흐름으로 조작 여부를 봅니다.
- 캡처는 `unmyeongdaero.com` 에서 찍습니다. localhost 는 쓸 수 없습니다.
- 테스트 결제창으로 찍어도 심사가 가능합니다.
