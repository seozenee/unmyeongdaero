캡처를 다시 만들려면 `captures/` 의 파일을 바꾸고:

## 심사에서 걸리기 쉬운 것들

- **소셜 로그인 계정은 심사용으로 쓸 수 없다.** 그래서 이메일·비밀번호 로그인을 따로 붙였다.
- **서비스 제공기간이 상품 페이지에 적혀 있어야 한다.** '영구 소장'만 적으면 12개월을 넘는
  장기 서비스로 읽혀 입점이 막힐 수 있다. 제공기간(즉시~24시간)과 열람기간을 나눠 적었다.
- **하단 사업자정보는 사업자등록증과 글자 하나까지 같아야 한다.**
- **죽은 링크를 두지 않는다.** 심사자가 누른다.
