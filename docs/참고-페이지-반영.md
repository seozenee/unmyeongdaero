# 참고 페이지 반영

사용자가 제공한 `page-a902163050be2a1e.js`를 실행하지 않고 구문 분석했다.
이 파일은 여러 상품과 언어가 묶인 Webpack 배포 파일이며 외부 모듈 ID와 결제·분석 서비스에 의존한다.
동작을 우리 앱의 사주 계산·상품·로그인·결제 경로로 옮겼다.

| 참고 파일의 구성 | 운명대로 적용 |
| --- | --- |
| 개인 이름과 강한 도입 | 계산된 성향과 가까운 사이·밖에서의 모습에 따른 질문 |
| 캐릭터 영상과 장면 전환 | 안내자별 영상, 팩폭사주 강호 전용 11컷 |
| 사주표와 성향 설명 | 쉬운 본문, 펼쳐 볼 입력 정보·사주표·계산 근거 |
| 분야별 잠긴 리포트 | 상품과 나이에 따른 3개 모자이크 카드 |
| 날짜·금액을 가린 예시 | 실제 숫자 없는 자리 표시와 구성 예시 안내 |
| 앞으로의 흐름표 | 계산에서 나온 여섯 달의 상세 풀이 미리보기 |
| 직접 적은 질문 | 원문 질문을 안전하게 표시하고 답변 항목 예고 |
| 장별 상세 목차 | 실제 구매 상품의 각 장에 세 가지 확인 항목 |
| 고정 구매 버튼 | 실제 운영 가격과 기존 결제 경로 |
| 입력 폼의 관계·직업·고민 | 관계 5종·직업 6종과 건너뛰기, 아이·학업 상품은 학습 단계, 자유 질문 |
| 인물 위에 한 번에 하나씩 묻는 입력 | 이름 → 날짜 → 성별 → 시간·도시 → 현재 상황 → 고민. 마지막 칸에서 바로 무료 풀이로 이동 |
| 스크롤에 맞춘 강조와 봉인 카드 | 회전하는 원형 장식, 눈 클로즈업, ‘탁’ 효과, 문장 등장과 봉인 카드 빛, 동작 줄이기 설정 지원 |
| 과거 경험을 짚는 대목 | 해당 연도의 계산 주제와 나이에 맞는 확인 질문 |

결제 전에는 AI를 호출하거나 읽는 중 문장을 바꾸지 않는다. 같은 입력과 기준일에는 같은 글이 나온다.
결제 후에는 구매한 목차에 맞춰 개인 계산과 사용자 질문으로 전체 보고서를 생성한다.
본문의 전문용어는 줄이고 상세 근거에서 실제 계산을 확인할 수 있게 한다.
구매 버튼은 무료 성향 풀이를 읽은 뒤 나타나며, 입력 화면에서는 무료 확인임을 분명하게 안내한다.
직접 선택한 현재 상황은 사용자 제공 정보로 표시하며 무료 본문과 유료 생성 양쪽에 연결한다.

## 팩폭사주 저장 오류

운영 `reports`에 `factbomb` 행이 빠져 `readings_report_slug_fkey` 오류가 발생했다.
빠진 행을 기존 운영값을 덮지 않는 방식으로 등록했고, 전 상품의 누락 여부도 확인했다.
이후 같은 상품 외래 키 오류일 때만 카탈로그의 상품을 중복 무시로 등록하고 한 번 재시도한다.
사용자 외래 키 오류와 알 수 없는 상품은 이 경로로 처리하지 않는다.

실제 데이터 없는 후기·특허·판매순위·마감 타이머는 만들지 않는다.
참고 파일의 고정된 만남 날짜·재산 액수를 실제 개인 결과로 저장하지 않는다.

## 강호 영상

기획과 프롬프트: `lib/story/webtoon-assets.ts`.
이미지: fal.ai Nano Banana / Nano Banana Edit. 영상: fal.ai Kling v3 Pro, 무음 5초.
결과: `public/webtoon/gangho/`, 연결: `lib/story/webtoon-manifest.json`.
모바일용 H.264, yuv420p, faststart로 압축하고 보이는 컷만 재생한다.
API 키는 생성 프로세스 메모리에만 전달하며 파일·매니페스트·브라우저 코드에 저장하지 않는다.
