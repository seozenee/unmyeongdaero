# 만세력 미리보기의 풀이 구조

참고 자료: 사용자가 제공한 11폴더의 스크린샷 35장과 용용사주 결과 페이지의 공개 미리보기.
원문의 문장을 복제하지 않고, 구성과 설명 방식을 운명대로의 계산에 맞춰 적용한다.

## 참고 자료에서 가져온 방식

- 한 사람의 핵심 대비를 먼저 짚고, 원국과 연결해 이유를 설명한다.
- 성격 이름만 붙이지 않고 말·표정·행동이 보이는 생활 장면으로 내려간다.
- 같은 강점이 어떤 조건에서는 부담으로 바뀌는지 설명한다.
- 구체적인 연도와 나이를 함께 짚고, 그 시기를 다음 행동에 연결한다.
- 분야별 장을 충분한 문단으로 읽게 하고, 마지막에는 구체적인 말이나 선택 기준을 준다.

합격률, 지능 점수, 평생 재산 액수, 병명 등 계산하지 않은 측정값은 도입하지 않는다.

## 적용된 순서

1. 자기 모습을 떠올리게 하는 개인 질문과 생활 장면
2. 입력 정보·원국·오행 확인, 성격의 안팎과 근거
3. 최근 네 해를 실제 계산해 두 해를 고르고, 그중 한 해의 과거 회고를 공개
4. 나이와 상품에 맞춘 두 분야의 해석
5. 앞으로의 시기와 선택에 관한 잠긴 질문
6. 전체 보고서의 목차와 기존 결제 경로

과거 해석에는 해당 해의 계산을 사용한다. 확인하지 않은 이별·전학·사고를 실제 사건으로 꾸미지 않으며,
구체적인 경험 후보와 당시를 떠올릴 질문을 제시한다. 모델이 연도나 근거 ID를 지어내면 채택하지 않는다.
시간 미상, 미성년자, 부모가 읽는 자녀 상품의 관점을 구분한다.

## 홈 상품명 재현과 수정

새로고침 직후에는 ‘종합사주’였지만, 같은 페이지에서 로고를 누르면 이전 제목이 다시 표시되는 것을
실제 브라우저에서 재현했다. 로고와 하단 홈을 문서 이동 링크로 바꿔, 이전 배포의 클라이언트 RSC를
재사용하는 경로를 피한다. 상품 데이터나 고객의 입력 정보를 수정하는 작업은 아니다.

## 검토 경로

개발 환경에서 `/dev/manse-preview?minor=1`로 미성년자 샘플을 확인한다.
`?slug=factbomb`으로 강호 샘플을 확인한다. 운영 환경에서는 이 개발 경로를 노출하지 않는다.

## 설명 문체 보완

계산 근거는 유지하되, 본문은 쉬운 생활의 말로 설명한다. 실제 글자·자리·십성의 상세 이름은
접힌 근거 영역에서 확인하고, 본문은 어떤 모습으로 이어지는지와 그 이유를 읽을 수 있게 한다. 결론을 먼저 말하고, 근거와 장면을 거쳐 대응으로 연결한다.
명리 해석의 범위와 측정하지 않은 수치를 만들지 않는 기준은 유지하되, 그 내부 기준을 고객 본문에 반복하지 않는다.
전체 보고서와 편집 단계는 같은 writing-style 지침을 사용한다. 결제 전 글은 계산한 여러 성향을
직접 조합한 완성본이며 AI 호출이나 뒤늦은 문장 교체를 하지 않는다.

상세페이지 진입 링크도 문서 이동으로 통일하고, 알려진 이전 질문형 상품명을 서버와 클라이언트 양쪽에서 보정한다.
상품 상세에는 가상 명식으로 계산한 읽을 수 있는 문체 예시를 제공한다. 고객의 실제 결과처럼 표시하지 않는다.

## 결제 전과 결제 후의 역할

결제 전은 구매 유도를 위한 개인 미리보기다. 계산된 중심 성향을 바탕으로 ‘이런 모습 있지 않으세요?’라는
질문을 먼저 던지고, 원국 근거와 과거 한 시기를 일부 보여 준다. 분야별 설명과 이후 시기의 구체적인 해법은
남은 이야기로 안내하며, 기존의 가격 표시와 결제 확인 절차로 연결한다.
결제 후 보고서는 참고 자료의 밀도로 이유·생활 장면·시기·실천을 충분히 풀어 쓴다.

## 결제 전 첫 화면의 속도와 안정성

사주 계산 후 완성된 미리보기와 구매 패널을 한 번에 보낸다. AI 호출, 지연된 본문 교체,
다 읽은 자리의 문장을 다시 쓰는 처리는 없다. 같은 입력과 기준일에는 같은 결과를 보낸다.
태어난 날의 가까운 관계, 태어난 달의 사회에서의 모습, 두드러진 성향을 서로 비교하고,
과거는 해당 해의 실제 계산 주제로 구별한다. 용어를 설명하느라 본문이 어려워지지 않게 한다.

날짜와 숫자가 가려진 카드는 구성 예시다. 실제 값처럼 고정된 날짜나 재산 액수를 숨겨 넣지 않는다.
전체 리포트는 구매 후 개인의 계산과 질문에 맞춰 생성하며, 구체적인 시기와 대응을 이어서 설명한다.
